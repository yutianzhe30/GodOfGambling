# 游戏机制 (Game Mechanics)

## 1. 核心玩法：特异功能梭哈 (Show Hand)
游戏完全围绕“梭哈”展开，规则参考传统五张牌梭哈，但加入了技能变数。
- **基础流程**：发底牌 -> 依次透明发牌并下注 -> 最终开牌比大小。
- **简化AI**：采用基于行为树的固定套路AI（激进型、保守型、偷鸡型），无需复杂的机器学习算法。

## 2. 气场系统 (Aura / MP)
气场是发动特异功能的唯一资源。
- **获取途径**：每回合自动回复少量；成功加注/跟注获得；使用消耗品（巧克力）瞬间回复。
- **UI表现**：进度条形式，满气场时角色会有发光特效。

## 3. 精简版特异功能 (Skills)
为控制实现难度，精简为三种最容易编程实现的技能：
1. **透视眼 (X-Ray Lens)** [消耗中等气场]：
   - **效果**：直接翻开对手当前的一张底牌，仅自己可见，持续一回合。
   - **实现**：直接读取对手底牌并在玩家本地UI上展示。
2. **偷龙转凤 (Card Switch)** [消耗大量气场]：
   - **效果**：将自己手里的底牌与牌库顶的牌交换。
   - **实现**：数组元素的简单互换机制 (Array Swap)。
3. **心理施压 (Pressure)** [消耗少量气场]：
   - **效果**：探测对手当前的“胜率自信度”（UI显示：极高/中等/心虚）。
   - **实现**：读取AI当前手牌的牌力评估值并映射为文本提示。

## 4. 道具与装备简述
- 仅保留核心道具，如**巧克力**（战斗中点击恢复气场），**赌神玉指环**（被动增加暴击/好牌概率，直接影响抽卡随机种子权重）。
