# 游戏机制 (Game Mechanics)

## 1. 核心玩法：特异功能梭哈 (Show Hand)
游戏完全围绕"梭哈"展开，规则参考传统五张牌梭哈，但加入了技能变数。
- **基础流程**：发底牌 -> 依次透明发牌并下注 -> 最终开牌比大小。
- **简化AI**：采用基于行为树的固定套路AI（激进型、保守型、偷鸡型），无需复杂的机器学习算法。

## 2. 气场系统 (Aura / MP)
气场是发动特异功能的唯一资源。
- **获取途径**：每回合自动回复少量；成功加注/跟注获得；使用消耗品（巧克力）瞬间回复。
- **UI表现**：进度条形式，满气场时角色会有发光特效。

## 3. 特异功能 (Skills)

> **动画规范**：透视/情报类技能**不翻开牌面**。效果通过悬浮半透明HUD窗口或Shader高亮边框呈现，保留神秘感。

共 7 个技能，分优先级实现：

### ⭐ 最高优先级（MVP阶段必做）

#### A · 透视眼 (X-Ray) — 气场消耗：中
- **单人效果**：在玩家1的HUD上叠加悬浮半透明窗口，显示对手当前底牌的Shader轮廓（不翻牌）。持续一回合，仅玩家可见。
- **双人效果（小刀触发）**：玩家2进行**读牌QTE**——按照闪烁顺序点击对应的牌位。成功则悬浮窗激活；失败则扣除一半气场，无效果。
- **技术实现**：读取对手底牌数组值，映射为HUD Sprite渲染，不改变牌面节点状态。

#### G · 变个3 (Three Change) — 气场消耗：极高 / 每局限一次
- **原型**：致敬原作《赌神》高进的标志性绝技——将手中任意一张牌变为3（最不起眼却最难被识破的牌）。
- **单人效果**：玩家选中手中一张底牌，直接将其数值改为3。消耗大量气场，每局仅可使用一次。
- **双人效果（协同触发）**：玩家1发出指令后，**玩家2必须在限时内同时按下确认键**（双端协同输入）。若未同步，技能失败，气场全扣。成功则以强烈的Shader闪光特效执行换牌。
- **技术实现**：修改对应牌的数据值为3，触发换牌动画Shader序列。

---

### 中优先级（阶段2迭代）

#### B · 心理施压 (Pressure) — 气场消耗：低
- **单人效果**：系统显示对手当前"胜率自信度"（极高 / 中等 / 心虚）文字提示。
- **双人效果（小刀触发）**：玩家2从三个"施压角度"中选择（面部表情 / 手势 / 语气语调），不同选择给出不同精度的情报（心虚/具体数值/虚张）。
- **技术实现**：读取AI当前手牌牌力评估值，映射为离散文字标签。

#### C · 偷龙转凤 (Card Switch) — 气场消耗：高
- **单人效果**：将自己手里的任意一张底牌与牌库顶的牌交换。
- **双人效果（小刀触发）**：玩家2在倒计时内点击选择要替换的目标牌（玩家1屏幕上该牌模糊化，玩家1不可见选择过程），确认后执行换牌。
- **技术实现**：数组元素互换 (Array Swap)，配合选牌UI倒计时控件。

---

### 低优先级（阶段3后续）

#### D · 读心术 (Mind Read) — 气场消耗：高
- **单人效果**：系统提示对手下一次行动的概率（加注 / 弃牌 / 跟注）。
- **双人效果（小刀触发）**：玩家2观察对手行为后，在三个信号旗中选择推送给玩家1（保守旗 / 激进旗 / 虚张旗），为主观判断，精度不保证。
- **技术实现**：读取AI状态机的当前权重分布并格式化输出；双人版为纯UI信号传递。

#### E · 气运加持 (Fortune) — 气场消耗：低
- **单人效果**：被动触发，本局抽牌时随机种子权重偏向高牌（直接修改权重参数）。
- **双人效果（小刀触发）**：玩家2通过**节拍QTE**按节奏点击打拍子，连击数越高，权重加成越强（上限为连击×5%额外权重）。
- **技术实现**：调整 `randi_range()` 的权重映射表；QTE计算连击数后通过RPC传值。

#### F · 金蝉脱壳 (Escape) — 气场消耗：特殊 / 每局限一次
- **触发条件**：主角筹码即将清零时可用（单人自动提示，双人仅玩家2可主动触发）。
- **单人效果**：紧急保底，保留底注不出局，气场清零。
- **双人效果（最终Boss关剧情节点）**：
  1. 主角强制输光（剧情触发）。
  2. 玩家2单方面激活金蝉脱壳，保住主角底注。
  3. 玩家2将全部气场传给玩家1后退场（叙事告别）。
  4. 玩家1获得一次性技能"**赌神附体**"（下一手牌必为最强牌型），独自完成决战。
- **技术实现**：强制玩家筹码归零事件 → 触发过场动画 → 赋予玩家一次性Buff节点。

## 4. 道具与装备
- **巧克力**：战斗中点击使用，瞬间回复气场。
- **赌神玉指环**：被动装备，增加抽牌时高牌权重（与技能E叠加，但上限封顶）。
