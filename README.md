# God of Gambling

**God of Gambling** is a 2D incremental idle game built with Godot 4, where players start with nothing and build their way up to becoming the ultimate gambling tycoon. The game features a robust progression system with multiple currencies, upgrades, and unlockable features.

## 🚀 Features



## 🛠️ Tech Stack

- **Engine**: [Godot Engine](https://godotengine.org/) 4.x
- **Language**: GDScript
- **Art**: [Kenney.nl](https://kenney.nl/) assets
- **UI/UX**: Custom Godot UI with modern design principles

## 📂 Project Structure

```
GodOfGambling/
├── assets/             # Game assets and resources
├── scenes/             # All game scenes and UI
├── scripts/            # GDScript files
├── shaders/            # Custom shaders
├── data/               # Game data and configurations
└── project.godot       # Godot project configuration
```

## 🎮 How to Play

1.  **Clone** the repository:
    ```bash
    git clone <repository-url>
    ```
2.  **Open** the project in Godot 4.
3.  **Run** the game and start your journey!
